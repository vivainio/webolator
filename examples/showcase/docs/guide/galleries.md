# Galleries

A gallery can sit anywhere on a page. Put a `gallery` fence where you want it and list a folder, files or a glob, one per line:

````markdown
```gallery
../assets/shots/
```
````

```gallery
../assets/shots/
```

Click a tile to zoom, then use the arrow keys to step through the images.

You can also pick images by name or pattern, and mix them:

````markdown
```gallery
../assets/shots/sunrise.png
../assets/shots/o*.png
```
````

```gallery
../assets/shots/sunrise.png
../assets/shots/o*.png
```

Text carries on as normal after the gallery.
