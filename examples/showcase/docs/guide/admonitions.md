# Admonitions

Call-outs use the MkDocs syntax, so existing content works unchanged.

!!! note

    A plain note. The title defaults to the type.

!!! tip "A tip with its own title"

    Types `note`, `tip`, `important`, `warning` and `caution` each have a colour.

!!! warning

    Other names such as `danger`, `bug`, `success` or `question` map onto those colours.

??? question "Collapsible"

    Start with `???` for a block that is closed until clicked, or `???+` to start it open.

GitHub-style alerts work too:

> [!IMPORTANT]
> Both syntaxes can be mixed on one page.
